# DTPBC Executive Photos Directory

Place your executive photos in this directory (`public/execs/`). The website automatically loads them on the Execs page!

Supported filenames:
- `president.jpg` -> Noah Park (President)
- `vp-karson.jpg` -> Karson Kung (Vice President)
- `vp-lucas.jpg` -> Lucas Deng (Vice President)
- `secretary.jpg` -> Wyatt Leung (Secretary)
- `treasurer.jpg` -> Kenny Le (Treasurer)
- `mal-vincent.jpg` -> Vincent Wong (Member-at-large)
- `mal-johanna.jpg` -> Johanna Vergizina (Member-at-large)
- `mal-jain.jpg` -> Jain Ram (Member-at-large)
- `mal-bela.jpg` -> Bela Asadon (Member-at-large)
- `t-sponsor.png` -> Mr. Willy Wan (Teacher Sponsor)

If an image is not uploaded yet, the website automatically falls back to an executive initials badge.
